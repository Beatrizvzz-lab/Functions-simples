# 📌 Exercícios de Funções em JavaScript

## Este projeto contém exercícios simples de funções em JavaScript, desenvolvidos para praticar conceitos fundamentais e melhorar a lógica de programação.

## Criação de Funções
Exercícios abordam funções nomeadas e anônimas.

## Parâmetros e Retorno
Prática de passagem de argumentos e retorno de valores.

# Tecnologias Utilizadas
